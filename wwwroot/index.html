使用说明

工具说明

扫描文件夹内 .cs 文件，展示类之间的引用关系与调用层级。

分析范围

仅展示该文件夹内已定义类型之间的引用；外部库/BCL 引用会被过滤。

调用层级

层级按最长引用链深度排列：第 0 层为入口类，每向下一层表示被上一层直接或间接引用。

类概要

点击类卡片或左侧目录树中的类型，右侧展示类概要：基本信息、成员大纲（含可见性图标）、输入/输出清单与调用树。

输入/输出按可访问性与读写启发式分类：可写字段/属性、构造参数为输入；只读字段、get-only 属性、方法返回值、event 为输出。

调用树

类概要面板底部可查看该类型的调用树；其下自动列出直接引用方。

在 Cursor 中打开

按住 Ctrl（macOS 为 ⌘）再点击可跳转的位置，会通过 cursor:// 协议在本机 Cursor 中打开对应文件行；普通点击仍在网页内查看源码。

  • 类卡片、图节点、目录树类型 → 类型定义行
  • 成员大纲、IO 端口 → 成员所在行
  • 调用树条目 → 类型定义行；Ctrl+双击或点击「引」→ 引用代码行
  • 源码弹窗内类型名、代码行、查找标尺标记 → 对应文件行

链接格式示例：cursor://file/D:/项目/文件.cs:100（末尾 :行号 决定定位；省略行号则只打开文件）。分析路径须为本机绝对路径，且与 Cursor 工作区一致；首次跳转浏览器可能询问是否允许打开 Cursor。
